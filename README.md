**Tr**
**MyQuran Projesi**
MySQL veri dosyaları `data_sql` klasöründe yer almaktadır. İki SQL dosyasının boyutu 25 MB'ı aştığı için, bunlar bir .rar arşivinde sıkıştırılmıştır. Proje, myquran.site web sitesine ait betik ve verilerden oluşmaktadır; site, Şeyx tarafından PHP ve MySQL kullanılarak tasarlanıp geliştirilmiştir.
**En**
**MyQuran Project**
The MySQL data files are located in the `data_sql` folder. Since the two SQL files exceed 25 MB in size, they have been compressed into a .rar archive. The project consists of the script and data for the website myquran.site; it was designed and developed by Şeyx using PHP and MySQL.
